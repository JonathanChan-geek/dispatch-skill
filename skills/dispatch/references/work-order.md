# Worker 工单模板

将下面内容补全后写入项目外的 UTF-8 文件，用 `--prompt-file` 传入。删掉不适用的行，不给 worker 留待猜测的接口或路径。

```text
【目标】
完成什么，以及为什么需要它。

【工作目录】
项目或 lane 的绝对路径。

【钉死项】
数据结构、接口签名、既有行为、禁止修改项。

【文件触碰集】
允许修改的文件/目录，与 lane manifest 一致。
只读任务写“不得修改任何项目文件”。

【改动清单】
逐文件写明预期变化、已知陷阱；不借机重构其他模块。

【验收命令】
精确命令、预期输出/阈值；L2 引用已冻结的 docs/gates/<slice>.md。

【PHASE 0 现实核对】
动工前核对工单与实际代码。冲突引用具体文件并说明影响；
没有冲突也列出检查了哪些实现/契约，不为找异议而编造异议。

【交付格式】
命令及原始输出或日志路径、diffstat、改动文件清单、未解决问题。
不以“已完成/测试通过”替代证据。

【边界】
不得递归派单；不得 stage/commit/merge/push 或切换分支；
不得修改触碰集外文件；不得修改 gates；验收结论由主控给出。
```
